# DualTrace 方法

DualTrace 分别为图像与文本构建内容驱动的检测器，输出越大表示越倾向于人工智能生成。两条链路共享“预训练表征、互补证据、响应蒸馏”的设计，但独立训练和推理，不要求图文配对，也不进行跨模态融合。

## 图像：多层表征与条件取证

### 1. 多深度表征

PE Core G/14 与 PE Spatial G/14 分别提取中心裁剪的多层 patch 表征。对零起始索引为 9、19、29、39、49 的各层 token，拼接通道均值与标准差，经独立投影后进行门控汇聚：

$$
u_l=P_l([\mu(H_l);\sigma(H_l)]),\qquad
a_l=\frac{e^{g(u_l)}}{\sum_j e^{g(u_j)}},\qquad
z=\sum_l a_l u_l.
$$

双编码器融合头将两路向量、绝对差、逐元素积及 logit 差作为交互特征，以残差修正平均 logit。CLIP ViT-L/14@336px 在末八个 Transformer 块中加入瓶颈适配器，汇集四层 CLS 特征；局部分支进一步统计 patch 分数的均值、上下尾均值与标准差。

### 2. 全局与原生尺度视图

图像短边缩放至 512 后取五个 448 裁剪，形成全局视图；原图仅在短边不足 448 时放大，再取五个裁剪，形成原生尺度视图。PE Core G/14 的十路特征经实例分类器获得平均响应，并依据几何类别选择全局或原生视图汇聚。彩色、灰度与 CLIP 特征同时提供互补表征。

### 3. 分类条件取证

以长宽比和短边分辨率划分近方形、低分辨率非方形及高分辨率非方形。归一化表征构造径向基核，结合类别条件掩码与全局、原生视图核形成多个 SVM 响应。专门证据包括人脸 ViT、汇聚 CLIP 中间层的 RINE、最近邻缩放残差驱动的 NPR，以及带 LoRA 的 SigLIP。基础融合先用冻结经验分布对齐分数，再按不确定性、几何类别及人脸检测结果调整取证分支权重。

### 4. 响应蒸馏

部署输出由 600 棵树的 ExtraTrees 回归器给出。输入为两项多实例响应、一项表征融合响应、三项条件核响应、RINE 与 NPR 响应，以及宽高，共十维。学生在冻结组件特征上拟合保存的批量排序教师分数，将教师响应转为可逐图计算的映射；该阶段使用伪标签，保留前端特征提取器。预测截断至 $[0,1]$，模型不以样本标识符为特征。

## 文本：连续编辑监督与字符响应

### 1. 连续编辑目标

外部语料包含人工文本、直接生成文本及机器改写文本。前两类目标分别为 0 与 1，改写文本相对其人工原文的目标为：

$$
y_{\mathrm{edit}}=1-\frac{\sum_{n=1}^{7}n\,
\cos(c_n(x_{\mathrm{human}}),c_n(x_{\mathrm{rewrite}}))}{\sum_{n=1}^{7}n},
$$

其中 $c_n$ 为规范化后去除空白的字符 n-gram 计数。该目标刻画字符片段变化程度。训练前按文本组排除与参考集重叠的样本，并去除标签冲突与重复文本。

### 2. 参数高效回归

Qwen2.5-1.5B-Instruct 配置单输出回归头，在注意力及前馈投影中加入秩 16、缩放参数 32 的 LoRA，并训练回归头。第一阶段对三类文本进行角色平衡，优化加权均方误差：

$$
\mathcal L=\frac{\sum_i w_i(f_\theta(x_i)-y_i)^2}{\sum_i w_i}.
$$

第二阶段混合目标域原文、规范化或标点扰动等变换、片段混合样本及外部语料回放，继续优化同一目标；四组总权重为 $1:0.5:0.5:2$。原文和增强样本使用构造标签，回放样本保留连续编辑目标。

### 3. 字符响应学生

字符支路采用 2–5 gram TF–IDF、次线性词频与 L2 归一化，最多保留 30 万维，以 Ridge 回归拟合保存的教师分数。该步骤在给定参考文本上学习伪标签响应，不更新语言模型；词表与回归系数保存后支持逐条推理。

### 4. 冻结分布融合

推理时，语言模型最多读取 2048 个 token；字符支路处理输入全文。分别以保存的参考分数排序数组定义经验分布映射 $F_Q,F_C$，最终计算：

$$
s(x)=\frac{1}{2}F_Q(f_\theta(x))+\frac{1}{2}F_C(r(x)).
$$

两路映射在部署时冻结，因此单条请求无需重新计算批内排序。输出用于生成倾向排序，不等同于经过概率校准的后验概率。
